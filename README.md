# EstadLiga

EstadLiga es una aplicación web centrada en LaLiga que permite consultar información sobre equipos, jugadores, partidos y clasificación.

El objetivo del proyecto es crear una plataforma donde los usuarios puedan consultar de forma sencilla diferentes datos relacionados con LaLiga.

## Funciones principales

- Información de los equipos.
- Información y estadísticas de jugadores.
- Clasificación de LaLiga.
- Calendario y partidos.
- Noticias.
- Quinielas y predicciones.
- Tienda para usuarios Premium.

## Tecnologías

El proyecto utilizará diferentes tecnologías y APIs para obtener y gestionar los datos necesarios para la aplicación.
